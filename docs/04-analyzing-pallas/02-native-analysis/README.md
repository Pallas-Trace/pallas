# Native Analysis Programs

Overview of built-in analysis tools for Pallas traces.

- 🖨️ [pallas_print](01-pallas-print.md): Print all the events of a trace
- ℹ️ [pallas_info](02-pallas-info.md): Get information about a trace
- ✏️ [pallas_editor](03-pallas-editor.md): Edit and manipulate traces
- 🗺️ [MPI Communication Matrix](04-communication-matrix.md): Analyze MPI communication patterns
- 📈 [Contention Score](05-contention-score.md): Compute contention scores with SCI metrics
- 📊 [Duration Histograms](06-histograms.md): Plot histograms of function durations
