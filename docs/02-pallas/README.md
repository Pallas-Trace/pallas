# Pallas Documentation

Pallas is a new trace format whose goal is to speed up post-mortem analysis.
It provides a clean C/C++ writing API, as well as an API for reading traces in both C, C++ and Python.

- 🎭 [Pallas Format Overview](01-format.md): All you need to understand the Pallas trace format
- 🔧 [Building and Installing Pallas](02-building.md): A detailed guide on all the options for Pallas
- ✍️ [Using Pallas](03-using.md): Write your own traces and store custom data
